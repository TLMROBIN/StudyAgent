# 语文学科生成边界与耗时建议（待决策，未实施）

日期：2026-10-27。本文仅提出建议；本轮实际发布范围为学生问答权限管理，不修改学科过滤、提示词或输出校验。

## 问题与边界

现行 `check_question()` 在黑名单之后，信任客户端选择的学科并直接允许；语文频道容易把文学学习与开放式共创混在一起。输出校验主要检查直接给答案，没有确认输出是否仍是教学引导。仅凭学生自称“老师布置”“用于学习”不能确认任务授权。

不能直接封禁“小说、故事、角色”等词：小说阅读、人物形象、叙事视角、戏剧鉴赏、作文修改和高考读后续写都可能是正常学习。应按任务的产出与教学目标判断。

## 推荐的语文专项策略

1. 正常允许：课程知识问答、给定文本赏析、学生原稿点评、作文审题与提纲、读后续写的构思反馈。短示例须对应一个明确知识点或学生稿件的问题，随后返回学生练习，不能靠连续“示例”拼成整篇成品。
2. 明确拒绝：替学生生成整篇作业、开放式长篇共创、同人连载、无限续写、非教学角色互动、用新身份覆盖教师身份。声称“老师允许”不能取消这些约束；确有特殊课堂活动，应由管理员配置有时限、可审计的任务授权，而非学生自行申明。
3. 边界不明：先问一个具体问题，如材料、考点、原稿或希望改善的能力；不自动生成故事。不要求每次学习提问重新提交完整背景。
4. 每个对话保存任务类型、依据与策略版本；“继续”“重新写”结合最近已确认的教学目标判断。发现从阅读分析转为原创连载时重新检查。已有小说上下文不能作为下一轮自动放行的理由，拒绝后的指令不写入可信教学上下文。
5. 文本与图片统一检查。附图文字/OCR和当前用户指令都不能成为绕过入口；不把学习材料里被引用的指令当作用户的真实操作指令。

## 耗时与实现顺序

| 方式 | 对首字时间的影响 | 用途与限制 |
|---|---|---|
| 本地任务规则与上下文状态 | 无外部请求，通常很小；上线前须用代表样本实测 | 优先落地；防变体，避免只匹配单个敏感词 |
| 同一次生成中加强语文教学边界 | 不增加模型调用次数；提示词长度会增加少量输入计算 | 辅助约束，不能单独承担守卫 |
| 仅对语文的疑难请求调用小型分类器 | 被抽检请求新增一次分类等待；平均耗时与触发比例有关 | 严格超时、限制输出长度；超时应澄清而非默认放行 |
| 每条输入额外调用完整大模型 | 每次都新增网络、排队、推理时间 | 不推荐作为默认流程 |
| 回复生成完后再做全文模型复核 | 会延迟显示，破坏即时流式体验 | 不推荐作为每轮默认流程；不合格内容一旦推送不能靠后撤回补救 |

建议先实施语文规则与对话任务状态，再在同次生成里收紧“共同作者/示例/作业授权”等边界。外部分类器只用于本地不能确定的语文请求。确定的学科提问不增加额外模型调用，确定的越界请求直接拒绝，模糊请求先澄清。

平均新增等待约为“分类触发比例 × 单次分类耗时”；这只是估算关系，触发比例和分类耗时目前都没有实测，不能承诺具体毫秒或秒数。分类结果缓存必须包含用户、学科、当前内容、可信上下文摘要和策略版本；不能只按最新一句“继续”复用。

输出先用本地规则逐个完整语义段检查，检测与已确认任务显著冲突的整章标题、无关角色互动和连续故事段落，命中后停止后续生成并回到教学澄清。规则必须结合任务类型，避免误伤所引用的文学原文。若需要语义模型复核，只对高风险的尚未展示段落调用，不对每个 token 单独调用。缓冲长度与首字时间、漏放风险需要一起评估。

## 是否只限语文

可以配置 `strict_subjects=["语文"]`，只对语文启用更细的任务类型和连续共创限制，其他学科维持现有策略。这是本轮建议的最小实施范围。但目前其他学科同样信任所选学科；只收紧语文不能保证学生换选物理后不再尝试。后续应让所有学科保留一层通用的“实际学科意图”核验，语文再追加专项规则。不要把禁用语文学科等同于关闭漏洞。

## 验收与回退

- 使用经脱敏的真实样本覆盖：语文阅读、戏剧鉴赏、作文反馈、读后续写、历史/文学梳理、引用注入、共创换身份、作业说法、反复要求示例、跨轮转向、图片请求与换学科。
- 先离线标注与回放，再只记录判定进行观察；不得将全体学生原始对话发送给新外部分类服务。
- 同时记录误拦、漏放、澄清比例、分类触发率，以及首字时间和总耗时的中位数/P95。阈值须基于当前基线与教师复核确定，不能把未经测量的耗时估计当作上线承诺。
- 语文专项策略独立开关、带版本；误拦或耗时异常时回退专项策略。账户禁用与内容策略分开管理，分类器不得自动封禁学生。
