## 推理开关与展示边界

学生请求新增 `deep_reasoning`，默认 false，复杂题可自主开启。支持开关的模型能力由服务端返回；不支持的模型拒绝 deep 请求，并且不保存学生问题。主模型与备用模型都透传模式。

深度请求不复用普通热点回答缓存。request_id 指纹包括深度选项，防止相同请求 ID 混用模式；默认 false 的旧指纹保持兼容。仍遵守管理员输出预算和现有苏格拉底输出校验。

SSE 增加 `reasoning_progress`，发送简短状态和耗时。另让模型在可见输出中生成 1–3 句公开学习思路摘要，通过完整安全校验后以 `learning_summary` 展示在折叠区；标签分片、未闭合、过长与答案泄漏都有防护。不发送、存储或转发 reasoning_content 原文，原文可能包含参考答案、未校验结论和与学生任务无关的信息。最后一步仍留给学生。内部推理本身不能作为已证明正确的解题依据。

进度在助手消息里默认折叠，展开区最高 140px，触控 summary 最低 44px。等待期间有耗时更新、心跳、停止生成；模式不可在正在发送时修改。该进度属于当前实时回复，刷新后的历史记录不保存内部推理。

DeepSeek 开关文档：https://api-docs.deepseek.com/guides/thinking_mode/
GLM 官方文档称 5.3-FLASH 强制思考；302AI 实测开关生效，因此 GLM 开关只限定实测供应商路由：https://docs.z.ai/guides/capabilities/thinking-mode

## 同题对照与准确度

三个小样本使用相同短物理教学 Prompt、相同输入，分别打开/关闭 thinking。只收集正文、使用量与时间；不是正式学科基准、P95 或课堂验收。

| 题型 | 普通首字 / 完成 | 深度首字 / 完成 | 人工检查 |
|---|---|---|---|
| 匀速圆周运动合力 | 14.24 / 26.27 秒 | 43.96 / 48.30 秒 | 两者识别速度方向变化；普通末尾出现“方向不变的加速度”不严谨表述 |
| 圆锥静摩擦 | 1.46 / 16.11 秒 | 47.95 / 60.99 秒 | 两者知道 μN 是最大静摩擦近似；深度更完整地区分摩擦方向与临界条件 |
| 母线与竖直轴夹角 | 8.64 / 19.70 秒 | 30.84 / 38.19 秒 | 普通擅自假设锥面光滑并提前写出半径关系；深度保留几何推导给学生 |

这些现象说明关闭思考可能影响复杂条件核查和表达准确性，不能由速度改善推断质量不变；同样不能由 3 个样本断言深度模式一定正确或量化准确率。日常短问题可选普通，复杂多过程题可选深度，仍应核对条件、单位和受力图。

上线浏览器实测另发现：深度模式仍可能把圆锥母线替换为“绳”，套错常见模型。因此深度提示进一步要求摘要及正文保留题干对象、装置和条件，资料冲突以题干为准，缺失条件须询问。该约束不能构成正确性保证。
