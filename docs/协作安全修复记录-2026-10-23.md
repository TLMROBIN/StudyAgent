## 新协作者启动与密钥管理

1. 从 Git 获取干净副本；不复制生产 data、env、artifacts 或备份。
2. 从 `.env.example` 建立自己的 `.env`；生成独立 JWT、管理员及 Grafana 密钥。生产的 DATA_ENCRYPTION_KEY 使用 `Fernet.generate_key()` 生成，和数据库分开备份；不要在 Issue、日志、PR 或截图中粘贴值。
3. 本地只用合成数据和受限测试模型账户，启用提交钩子；CI 扫描不能代替数据使用授权。
4. 监控通过 SSH 隧道访问，例如 `ssh -L 3001:127.0.0.1:3001 user-rack-server`。本机实际 Grafana 端口以部署配置为准。
5. 生产迁移前备份 SQLite 和对应密钥，停止写入后执行迁移并验证完整性。旧明文备份继续按敏感数据保管；升级不会自动改写历史备份，也不能把新加密库与同目录密钥一起交给协作者。
