# 发送与停止按钮遮挡修复（2026-10-27）

## 复现与原因

在本机真实 Vue 页面注入学生数据（不向生产提交消息），用 ego-browser 测试。
375×300、展开侧栏、正在生成：输入区底边 380px，停止按钮底边 326px，
禁用的“正在思考”按钮底边 380px，均超出 300px 视口。
原因是展开侧栏压缩正文宽度，操作区换行，而输入区不允许收缩，页面又固定高度并裁切溢出。
这能解释小视口操作区不可用；尚不能断言用户所说的导航栏属于网页侧栏还是 Android 系统导航栏。

## 修复

- 生成时只显示可操作的停止按钮，发送时显示发送按钮。
- 小屏将推理选项与操作按钮分行，限制展开侧栏宽度。
- 输入区可收缩、滚动，按钮区粘在底部；阅读区溢出不覆盖操作区。
- 增加底部留白，使用 safe-area-inset-bottom，并声明 viewport-fit=cover。
- 更新上次固定聊天布局改造后遗留的焦点测试：跟随最新消息，不滚动整个固定页面。

  检查按钮完整位于视口与侧栏右侧，并通过 elementFromPoint 验证中心点击命中按钮；24/24 通过。
