# 学生使用信誉分与 Laya 分档复核方案

2026-11-20 · 讨论稿

## 目标与可行性

技术上可行。建议把信誉分用于决定一道题能否跳过远程复核。近期有稳定学习记录的学生可以更快通过部分边界题。近期有已确认滥用记录的学生，更多边界题进入原有分类器。所有学生都可以提交同样的学科问题，远程分类器使用相同的学科判定标准。分数只反映近期可核实的平台使用行为，不用于成绩、评优、纪律处分或学生排名。

是否值得实施，取决于减少了多少正常问题的最终误拒，以及为此多放行了多少越界请求。一次先前的离线回放中，43 条历史正确拒绝在原路径全部继续被拦截。样本来自拒后重问，且回放使用内网模型代替生产远程复核，这一结果不足以给信誉分各档确定阈值。

## 一个可试算的计分版本

以下数字仅供离线试算。分数范围 0–100，初始 70。每周按北京时间周一至周日审阅上一个完整周。以一次围绕同一目的的对话为事件，同一事件的重试、改写和多轮消息合并。

| 周审证据 | 建议处理 |
|---|---|
| 至少两段独立学习对话，经复核确认用于解题、知识学习、作文指导或学习管理 | 当周加 3 分，每周至多一次。同一天也可以满足条件。 |
| 经明确提醒后，仍持续提出相同的明确越界请求，且有完整上下文、账号归属可信、教师确认 | 每个独立事件减 5 分，每周最多减 10 分。 |
| 单次偏题、询问使用边界、模型拒答、证据不足、账号可能共用 | 0 分。先帮助学生澄清或回到学习话题。 |
| 跨频道提问、做错题、反复要求解释、题图模糊、学生纠正导师或对误拒表示不满 | 按实际学习用途审阅，均不能单独作为扣分依据。 |

同一周同时有正负事件时分别记账再相加。每周以最近八个完整周的有效事件重新计算，过期事件自然退出。无活动的一周记 0 分。新用户和长期停用者都能从中性档开始。举例来说，70 分学生有两段确认的学习对话，加 3 分；若同周还有一个教师确认的独立滥用事件，则周末为 68 分。学生申诉成功后撤销对应事件，立即重算。

周审须同时覆盖放行和拒绝。加分样本按账号从正常完成的对话中抽取，每周抽取上限统一；扣分候选从明确越界事件中筛选。题量多、重试多都不会线性改变分数。若审阅能力不足导致学生之间覆盖严重不均，应先调整抽样，再考虑启用个人分数。

## 分数如何影响首问与追问

| 信誉分 | 首问阈值候选 | 追问阈值候选 |
|---|---:|---:|
| 80–100 | 0.844 | 0.928 |
| 60–79 | 0.854 | 0.938 |
| 0–59 | 0.864 | 0.948 |

中性档沿用当前生产阈值，两侧各变化 0.010，仅用来产生第一版对照数据。首问与追问分别校准，Laya 的输出分数不能直接解释为正确概率。例如首问得分 0.849，在示例高分档可直放，在其余两档交远程复核。实际效果由复核最终结论决定。

按请求取学生当时生效的档位，在已有资格调用 Laya 的位置比较原始学科分数。禁止修改共享模型客户端的阈值，以免并发学生互相影响。追问继续带前文，保留已有的上一轮验证条件与连续直放限制。全局安全规则和苏格拉底输出校验对各档一致。只复用与信誉无关的原始模型分数或远程语义裁决，沿用原有缓存优先级。不能把某人的按档放行决定缓存给其他学生。记录每次实际采用的模型版本、档位策略版本和阈值，便于复盘。

## 谁复核，哪些记录可以归到学生

内网模型负责提取候选、给出标签和依据。教师核对所有扣分候选的原始上下文，确认提醒和后续行为确实属于同一事件。分歧或归属不明时保持 0 分。系统的拒绝、放行、此前信誉分和学生对导师的异议都不能充当判定滥用的证据。周审人员先看行为再看计分结果，避免低分产生更多审查、更多扣分的循环。

已建会话可以按校内账号归属。新上线的建会话前拒绝审计故意不保存学生标识，这批样本只用于整体误拒分析。首版可以仅使用可归属的会话，无需改造匿名首问审计，更不能用时间、文本、IP 或设备反推学生。共享账号、演示账号、疑似冒用及无法确认归属的账号保持中性路由。

建议以可撤销的事件流水保存周次、内部账号、证据引用、审阅人、规则版本、变动量及撤销状态。复用现有会话访问权限读取证据，避免复制整段学生对话。事件有稳定唯一键，重跑周审不会重复加扣分。更正和申诉保留处理记录。基础设施故障、档位缺失或评分服务不可用时，采用现网中性阈值。

## 学生看到什么

个人页显示当前分数、上次更新时间、近八周变动、具体依据和申诉入口。例如“本周 +3，两次独立的学习对话已核实”。扣分说明给出对应轮次、已确认的行为、分值和预计失效周。学生可查看自己的记录，教师按授权范围处理申诉。对正在申诉的扣分暂停其路由影响直至复核。首期不设公开榜单，界面说明低分时边界问题会多一次复核，学科答疑资格对所有学生一致。

## 何时值得上线

1. **离线验证。** 用历史可归属会话按周回算，预测某周的路由时只用此前已经审结的周。按学生和会话隔离调参与评估，分别报告首问、追问、各档、低频学生和跨学科提问的结果。专门检查“高分账号突然转向滥用”和“低分账号回到正常学习”。
2. **影子运行。** 建议先积累至少四个完整教学周，后台同时计算现网与候选路由。逐条复核两者分歧，再随机复核一部分一致样本。报告正常学科题的最终误拒率、正常学习会话至少遭一次误拒的比例、越界题最终误放率、远程复核次数与等待时间，同时列出分子、分母和不确定区间。四周是观察起点，样本稀少的档位继续收集数据。
3. **小范围试点。** 只有在配对样本上看到正常学习受益、低分档正常题的最终误拒可接受、各档误放符合预先约定的预算，并具备教师复核和学生纠错能力时，再开放学生可见分数与实际分档。先前短答实验中的 30% 预算衡量的是特定样本的模型直放误放率，不能直接用作最终裁决的上线标准。
4. **可独立停用。** 用单一开关恢复统一阈值，并可重算受错误标签影响的分数。若只有耗时改善而最终误拒未下降，应如实衡量延迟收益是否值得教师审阅和申诉成本。

本稿仅供决策，未创建评分表、周审任务或生产配置。
